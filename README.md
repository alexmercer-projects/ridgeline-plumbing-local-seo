# Ridgeline Plumbing: local SEO before and after

A before-and-after demo of on-page local SEO for a made-up plumber in Fort Collins. A weak three-page site is rewritten so titles, meta descriptions, headings, alt text, NAP consistency, and tap-to-call are fixed.

This is a concept demo. Ridgeline Plumbing is not a real company. The street address and phone number are placeholders (the phone uses a 555 number). No ranking results are claimed. Both versions were scored with the same automated on-page check; those scores are in the case-study page, not proof that the site would rank.
